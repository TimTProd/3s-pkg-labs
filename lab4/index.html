Базовые растровые алгоритмы

Начало Конец

Целые координаты (x; y) соответствуют центрам клеток дискретной сетки: клетка (x; y) занимает на плоскости квадрат от x − 0,5 до x + 0,5 по горизонтали и от y − 0,5 до y + 0,5 по вертикали. Линии сетки проходят по границам клеток, то есть по полуцелым значениям, а оси координат – через центры клеток с номером 0. Масштаб меняется ползунком или колёсиком мыши, сетку можно сдвигать мышью.

Пошаговые вычисления

Стресс-тест

100 000 случайных отрезков во всех 8 октантах и 50 000 окружностей. Время измеряется только для заполнения виртуального растра, без отрисовки; дополнительно – время чистых вычислений без записи в растр.
